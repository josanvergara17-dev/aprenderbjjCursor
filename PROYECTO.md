# Mapa de arquitectura

## Resumen

El repositorio está en el commit inicial. No hay aplicación, módulos, servicios, dependencias ni framework. La arquitectura de software todavía no está definida: solo existe la raíz del repositorio y su historial de git.

## Raíz

| Ruta | Para qué sirve |
| --- | --- |
| `README.md` | Punto de entrada del proyecto. Existe y está vacío. |
| `.cursorrules` | Directrices de estilo y de trabajo deducidas del estado actual del repositorio. |
| `PROYECTO.md` | Este mapa: qué hay y para qué sirve. |
| `TODO.md` | Lista de tareas abiertas. |

## Carpetas

No hay carpetas de código ni de documentación.

La única carpeta del árbol es `.git`. Guarda el historial de versiones, las referencias y la configuración del remoto. No es parte de la arquitectura de la aplicación y no se documenta como módulo.

## Historial relevante

- Rama `main`.
- Un commit: `Add initial README file`, que añade `README.md` vacío.

## Qué no hay todavía

- Código fuente.
- Pruebas.
- Configuración de build, linter o CI.
- Dependencias o gestor de paquetes.
- Licencia.
